# WOofe — Luxury Dog Lifestyle & Architectural Furniture

> **"Luxury furniture for dogs, designed for the home."**  
> *Independent concept redesign — not affiliated with or commissioned by WOofe.*

A digital flagship redesign concept for **WOofe**, elevating canine lifestyle essentials into quiet Scandinavian architectural statements that seamlessly integrate with modern interior spaces.

---

## ✨ Features & Highlights

- **Cinematic Hero**: Layered depth parallax (GSAP ScrollTrigger), desktop mouse-driven 3D perspective tilt (Framer Motion), and fluid typographic reveals.
- **The Details Matter**: Pinned horizontal storytelling experience traversing *Material*, *Comfort*, *Craft*, and *Design* with technical SVG path-drawing callouts.
- **The Bear Bed Experience**: Cinematic product exploration page featuring macro fabric inspection, ergonomic curve overlays, craftsmanship callouts, and a sticky Add-to-Cart purchase bar.
- **Interactive Split-Screen**: Framer Motion spring layout transitions (50/50 → 65/35) highlighting *"For Them / For Your Home"*.
- **Editorial Material Hotspots**: Macro bouclé texture photography with interactive pulse markers and floating editorial spec cards.
- **Tactile UI & Interaction**: Custom lerp cursor (`VIEW`, `EXPLORE`, `DRAG`), spring magnetic button attraction, and smooth route transitions.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation & Motion**: [GSAP](https://greensock.com/gsap/) + ScrollTrigger, [Framer Motion](https://www.framer.com/motion/)
- **Icons**: Lucide React
- **Typography**: DM Serif Display + Inter (via Google Fonts)

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

To create a production build:

```bash
npm run build
npm run start
```
